# Firework Studios

A standalone static website for Firework Studios, the creative studio within Convex, LLC.

## Local preview

Open `index.html` in a browser, or run a local static server:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000.

## Publishing

The site is plain HTML, CSS and JavaScript and can be hosted on GitHub Pages or any static host. No build step or paid service is required.

## Before launch

- Confirm the public contact email and replace the example `hello@fireworkstudios.com` address in `index.html`.
- Replace the clearly labelled concept visuals in Selected Work with approved project work when available.
- Add final privacy/legal details if analytics or contact-form processing is introduced.
